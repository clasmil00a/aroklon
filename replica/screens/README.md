# Reference screenshots

No screenshots of the original product were captured for this project.

The recon map (`recon.md`) was built from public text sources: the product's
marketing site, FAQ, help center articles, and third-party reviews. Those
sources describe the screens, fields, workflows and keyboard shortcuts well
enough to rebuild the functionality and layout patterns without copying assets.

Screenshots in this folder would be reference only and must never be shipped in
the clone.
