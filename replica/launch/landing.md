**Headline:** POS kasir Windows untuk toko kecil. Gratis, lokal, cepat.

**Sub-headline:** Buka aplikasi dan mulai transaksi segera — tanpa SQL server, tanpa berlangganan, tanpa paksa memasukkan produk terlebih dahulu.

**Button:** Unduh Gratis

**Screenshot:** Jendela utama kasir dengan keranjang produk dan tombol checkout.

---

## 2. The Problem

**POS Anda lambat dan terkunci di balik pembayaran.**

Banyak aplikasi kasir butuh SQL server yang memperlampaui kebutuhan toko kecil, sehingga aplikasi menjadi lambat dan memerlukan pengaturan yang rumit. Fitur berguna terkunci di balik versi berbayar ("Pro"), dan pelanggan harus membayar berlangganan bulanan untuk fitur dasar.

**Anda paksa memasukkan produk sebelum bisa menjual.**

Beberapa sistem kasir menuntut Anda membuat daftar produk lengkap sebelum transaksi pertama, sehingga toko baru tidak bisa segera mulai beroperasi.

**Cetak struk tidak terkontrol.**

Beberapa sistem mencetak struk atau tikit dapur setiap kali meja disimpan, bahkan saat tidak diminta.

---

## 3. How It Works

**Langkah 1:** Buka TokoKasir, pilih "Kasir" dari menu utama.

**Langkah 2:** Cari produk dengan kode atau nama (tekan F3), tambahkan ke keranjang, sesuaikan jumlah.

**Langkah 3:** Pilih metode pembayaran, selesaikan transaksi, cetak atau simpan struk.

---

## 4. Features

**Local-first, no SQL server**
Semua data tersimpan di komputer Anda, tidak perlu server. Cepat dan berfungsi offline.

**Gratis, tanpa berlangganan**
Semua fitur tersedia tanpa pembayaran bulanan. Tidak ada fitur terkunci di balik versi Pro.

**Quick sell mode**
Buka aplikasi dan mulai transaksi segera — tidak perlu memasukkan produk terlebih dahulu.

**Satuan jual dengan konversi**
Jual per dus, kg, pcs, atau satuan lain dengan faktor konversi otomatis.

**Daftar harga per satuan**
Harga eceran, grosir, atau per satuan untuk setiap produk.

**Pelanggan dan daftar harga default**
Tetapkan daftar harga default per pelanggan, diterapkan otomatis saat transaksi.

**Kas masuk dan keluar**
Catat semua transaksi kas, lihat histori perpindahan uang.

**Refund dan pengembalian stok**
Refund transaksi dan stok dikembalikan otomatis.

**Tutup hari dengan laporan Z**
Hitung kas, cetak laporan Z, tutup register. Tersedia laporan X tanpa menutup.

**Laporan lengkap**
Penjualan, stok, pembayaran, pelanggan, dan pajak. Ekspor ke CSV dan TXT.

**Tema gelap dan terang**
Pilih tema yang nyaman untuk mata Anda, disimpan per pengguna.

**Cadangan harian otomatis**
Database dicadangkan setiap hari saat aplikasi dibuka, riwayat 30 file.

**Kunci pesanan**
Tahan pesanan dan lanjutkan nanti, dengan opsi kunci agar tidak diubah oleh register lain.

**Gabung dan pisahkan item keranjang**
Gabungkan item yang sama atau pisahkan keranjang menjadi dua baris.

**Pintasan keyboard**
F3 untuk pencarian produk, Enter untuk tambah, Esc untuk batal.

**Peringatan usia**
Periksa usia pembeli untuk produk yang membatasi usia.

**Cetak struk terkontrol**
Cetak struk hanya saat Anda memilih, tidak otomatis setiap kali menyimpan.

## 6. FAQ

**Bisakah saya mengimpor data dari aplikasi kasir lain?**

Saat ini impor data dari aplikasi lain belum tersedia. Data dapat dimasukkan secara manual melalui editor produk dan pelanggan.

**Apakah TokoKasir perlu internet untuk beroperasi?**

Tidak. Semua data disimpan lokal di komputer Anda. Aplikasi berfungsi sepenuhnya offline.

**Apakah ada batasan jumlah transaksi?**

Tidak. Tidak ada batasan jumlah transaksi, produk, atau pelanggan.

**Bisakah saya mencetak struk ke printer termal?**

Ya. TokoKasir mendukung printer termal Windows untuk struk 80mm.

**Apakah data saya aman?**

Semua data tersimpan di komputer Anda (%LOCALAPPDATA%\\Aroklon\\). Cadangan harian otomatis dengan riwayat 30 file.

**Bagaimana jika saya lupa kata sandi admin?**

Kata sandi dapat di-reset melalui database atau dengan bantuan administrator sistem.
